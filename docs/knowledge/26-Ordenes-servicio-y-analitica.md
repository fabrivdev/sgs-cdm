### Fuentes, identidad y permisos

La versión inicial de `service_orders_billing_v1` en `supabase/migrations/20260925200000_service_order_billing_efficiency.sql` reutilizaba `ventas_servicios_movimientos_enriquecidos` para todos los períodos. Primero se optimizó la carga y después se reemplazó el contrato por `service_orders_billing_v2` para corregir la fuente de tarifa (ver corrección más abajo). Conserva población comercial, clasificación de rubros, moneda/base de IVA, notas de crédito y vínculos. Para el sistema actual exige `linked_service_order`; para histórico conserva el vínculo único factura + sucursal + año de Ventas. Número completo de OS, prefijo de sucursal y ceros iniciales no se eliminan; sólo normaliza espacios externos/mayúsculas. Colisiones normalizadas quedan ambiguas, no se toma la primera OS.

La función agrega documentos, rubros, fecha de última factura positiva y horas equivalentes por OS. El contrato JSON no se trunca por el límite de filas de PostgREST. `billing.ts` consulta lotes disjuntos de hasta 250 OS, exige exactamente una respuesta válida por identidad y descarta toda la parte financiera si falla un lote. Los datos operativos conocidos permanecen visibles con aviso y reintento; no se muestran importes parciales ni valores OS como respaldo financiero.

RPC de sólo lectura, restringida a usuarios autenticados con **ambas** secciones `servicios.ordenes` y `servicios.ventas`. No amplía permisos, no ejecuta SQL remoto ni cambia RLS de facturas. ### Cálculo y límites

- **Horas facturadas equivalentes = importe financiero de mano de obra / tarifa horaria `PRECIO` de las líneas MA01 de esa OS y tipo de tiempo.** La primera implementación usaba `facturacion_lineas_importadas.valor_unitario`: era incorrecta para facturas de una unidad que representa el trabajo completo, no una hora. No volver a ese respaldo ni usar `VALFAC`, `CNTFAC`, una tarifa fija o total/cantidad como tarifa horaria.
- La tarifa puede variar entre Cliente, Garantía e Interno, e incluso dentro del mismo tipo. Conservar documento, moneda, tipo y tarifa por línea antes de agregar la OS. Repuestos, kilómetros, terceros y auxiliares no aportan tarifas de mano de obra. Un descuento reduce el importe facturado, no se transforma en una nueva tarifa para forzar eficiencia 100%. No interpretar el indicador comercial como una prueba aislada del desempeño de una persona.
