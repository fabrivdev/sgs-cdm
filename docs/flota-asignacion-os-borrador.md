# Decisión: sin carga manual por salida u OS

El vínculo vehículo-salida/OS fue evaluado y descartado para esta versión porque duplicaría trabajo operativo. No forma parte de la migración y no se modifican las OS existentes.

Flota conserva kilometraje verificable por vehículo a partir de lecturas reales. La interfaz vigente muestra únicamente catálogo, estado, odómetro, recorrido del período, lecturas y correcciones; no presenta facturación ni gráficos.

No se atribuye facturación a vehículos. Tampoco se infiere por técnico, chasis de la máquina atendida o cercanía de fechas. El importe `billing.travel` y las tarifas no representan distancia.
